# Интернет-магазин

## Описание:

API-приложение для трекинга полезных привычек

## Установка для разработчиков
* Клонируйте репозиторий:
  ```git clone https://github.com/stepanbaidakov/online_learning.git```
* Запуск проекта локально```docker compose up```

## Использование

* Возможность регистрации и дальнейшей авторизации для создания уроков и курсов через API запросы по IP-адресу
  111.88.157.137
* Возможность покупки курса и оформление подписки на обновления курса

## Документация

Для получения дополнительной информации обратитесь к документации в swagger http://111.88.157.137:80/swagger/ или
http://111.88.157.137:80/redoc/
