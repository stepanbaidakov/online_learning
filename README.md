# Интернет-магазин
## Описание:
API-приложение для трекинга полезных привычек

## Установка
* Клонируйте репозиторий:
```git clone https://github.com/stepanbaidakov/e-commerce.git```
* Запуск проекта ```docker compose up```

## Использование
* Возможность регистрации и дальнейшей авторизации для создания полезных привычек через API запросы
* У полезных привычек может быть указаны либо приятные привычки в качестве вознаграждения, либо свое
вознаграждение на прямую
* Переход и активация бота https://t.me/HaibitGoodBot для получения напоминаний по привычкам
## Документация
Для получения дополнительной информации обратитесь к документации в swagger http://localhost:8000/swagger/ или
http://localhost:8000/redoc/
